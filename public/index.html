ChatGPT Share Archiver

Paste a public ChatGPT conversation share URL. The server opens it in Chromium, scrolls through lazy-loaded content, expands user-visible disclosure sections, and returns a readable static HTML file with code blocks preserved.

This archives only content exposed by the shared page to an ordinary browser. It does not extract hidden/private reasoning, internal application state, account-only data, or content that the share link itself does not expose.
