Chat name is detected from the shared page title and is used for the downloaded HTML filename when available. Timeline markers count visible ChatGPT date/time separators and Branched from notices retained between turns. Scanning always shows traversal step/status, but ordinary step movement does not count as substantive progress. Detail describes the current operation. Oldest retained is the cumulative earliest turn already stored and can legitimately stay at turn 1 once found. Mounted first is the live virtualizer frontier and should continue changing as ChatGPT mounts/unmounts regions. Expanding shows the most recent disclosure only while its turn remains in the current mounted range; it clears when that turn is virtualized away. Live-preview snapshots are generated only while a preview window is open; the final archive embeds retrievable images.
