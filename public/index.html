ChatGPT Share Archiver

Paste a ChatGPT conversation share URL. Chromium scans the conversation in both directions, expands visible reasoning/tool disclosure trees, captures virtualized turns as they appear, and exports a static HTML page with code blocks preserved.

The app expands user-facing content that the shared page exposes to the browser. It does not inspect private model state, hidden network payloads, account-only data, or reasoning that the shared page itself does not expose.
