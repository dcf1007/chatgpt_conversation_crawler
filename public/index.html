Authenticated mode reuses the local browser-profile directory and verifies the ChatGPT session before crawling. If ChatGPT expires the session, open the login window again. Chat name is detected from the shared page title and is used for the downloaded HTML filename when available. Timeline markers count visible ChatGPT date/time separators and Branched from notices retained between turns. Scanning always shows traversal step/status, but ordinary step movement does not count as substantive progress. Oldest retained is the cumulative earliest turn already stored. Mounted first is the live virtualizer frontier. Expanding clears when its turn is virtualized away. Live-preview snapshots are generated only while a preview window is open; the final archive embeds retrievable images.
