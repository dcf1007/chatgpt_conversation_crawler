ChatGPT Conversation Crawler v1.7.1-beta3-dev

Development diagnostic prerelease.

Beta3 makes retained semantic evidence, rather than physical viewport geometry or disclosure presentation state, the crawler's convergence authority. It separates observed DOM generations from semantic turn revisions, completes confirmed disclosures at the resulting semantic revision, passively discovers the corpus in both directions before turn-local processing, uses guarded whole-turn coverage, pins exact traversal endpoints with setTop(), and revalidates only semantic dirty work.

Mount retention now captures already-mounted turns immediately, retains concrete observed nodes that can disappear in the same mutation batch, watches targeted semantic attributes, and is drained/sealed before the final closure decision. Capture-only snapshots no longer open live native details. Final convergence/status is conditional on actual oldest-edge, traversal, turn-processing, logical-disclosure, and retention-closure invariants.

The development manual comparison remains enabled on dev and now reconverges the selected target through the same production turn-local fixed-point primitive.

Run the platform setup script if dependencies are not installed, then use the matching start script. This diagnostic prerelease must not be merged into clean main without the separate promotion/cleanup step.
